CAMBIO VE — Tasas BCV y Binance para Android

Archivos de la aplicación web instalable (PWA): index.html, manifest.webmanifest, sw.js e icon.svg.

IMPORTANTE: para que Android permita instalarla y consultar las fuentes, los archivos deben publicarse en un alojamiento HTTPS. Abrir index.html directamente desde Descargas (file://) puede bloquear las consultas a internet. Después de abrir el enlace HTTPS en Chrome para Android, usa el menú ⋮ → Instalar app / Agregar a pantalla principal.

Actualiza al abrir y cada 30 minutos mientras queda abierta. El BCV suele publicar en días hábiles; la app muestra la fecha efectiva que devuelve la fuente y no inventa una tasa para días sin publicación. Los valores Binance P2P dependen de los anuncios, monto, método de pago y lado de compra/venta. El euro Binance es una equivalencia EUR/USDT × USDT/VES, no una tasa oficial EUR/VES.

La consulta BCV usa la API pública DolarApi, cuya documentación indica que la fuente de sus endpoints oficiales USD y EUR es el Banco Central de Venezuela. Consulta el BCV original desde el botón BCV dentro de la app.
